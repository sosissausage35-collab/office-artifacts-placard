An entry for the [make.fun](https://make.fun/bounty/u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2) contest **Office Artifacts: The One-Line Placard Contest**: a single line of at most 180 characters, a museum placard for an ordinary office object written as if it were an ancient artifact dug from a lost civilisation.

## The placard

> Votive Tablet (sticky note), c. 2019, adhesive paper. Inscribed 'call mum back' in fading ink, left at the shrine of the photocopier. Anonymous donor.

The conceit: a sticky note is a votive tablet, and the most banal reminder imaginable is preserved as a sacred inscription, left as an offering at the shrine of the photocopier. Catalogue date, material and donor included; the joke is left unexplained, as a good curator would.

## Run

```sh
node main.ts
```

`main.ts` is deterministic — it writes the same fixed line to `/output/entry.txt` on every run (150 characters, one line, no trailing newline). No network, no secrets, no files read outside this repository.
